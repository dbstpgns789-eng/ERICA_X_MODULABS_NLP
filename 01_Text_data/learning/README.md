# 노드 1·노드 2·프로젝트 학습 기록

정리일은 2026-11-06이다. 사용자가 “오늘 함께 한 내용 전부”를 기록하도록 요청한 대화를 주제별로 재구성했다. 대화가 날짜 경계를 지나 이어졌고 모든 발언의 시각을 확보하지 않았으므로, 전체 학습이 이 날짜 하루에만 이루어졌다고 단정하지 않는다. 수업 기준일 2026-11-03과도 구별한다.

이 기록은 축어 전사본이 아니다. 사용자의 질문·직접 설명, Codex의 보충 설명, 실제 Colab 출력과 사후 해석을 구별했다. 강사 제공 원문 노트북은 공개하지 않고 파일명과 필요한 위치만 적었다.

## 사용자가 요청한 학습 방식

- 원본 노드의 셀 순서를 따른다. 건너뛰거나 다른 설명 순서로 재배열하지 않는다.
- “필수다”, “성능을 높인다”에서 끝내지 않고 왜 필요한지와 작동 원리를 설명한다.
- 한 번에 완성된 노트북을 넘기기보다 셀의 목적·입출력·결과를 함께 이해한다.
- 결과를 해석하면 다음 실행 셀도 이어서 제시한다. 매번 “다음으로”라는 허락을 요구하지 않는다.
- 예측·회고는 사용자의 생각을 바탕으로 다듬으며, 에이전트가 대신 생각한 것을 사용자의 이해로 기록하지 않는다.
- 파일·출력으로 확인한 사실과 추론을 구별한다. 메시지를 다시 보냈다는 사실만으로 Orca 좌클릭 문제가 해결됐다고 단정하지 않은 사례도 이 원칙을 확인한 대화였다.

## 자료와 작업 환경

기준 자료는 사용자가 지정한 4개 ZIP이다. 이 학습에서는 `LMS콘텐츠/1 텍스트 데이터 다루기.ipynb`와 `2 멋진 단어사전 만들기 [프로젝트].ipynb`를 중심으로 진행했다. `PPT자료/자연어처리-day2.pdf`는 별도 슬라이드이며, 현재 노드와 페이지가 일대일로 대응한다고 가정하지 않았다.

프로젝트 실행은 Google Colab Tesla T4에서 사용자가 수행했다. Codex는 셀과 설명을 제시하고, 돌아온 출력 및 최종 다운로드 파일을 검토했다. 실제 대면 강의를 듣거나 녹음을 확인한 것으로 기록하지 않는다. 녹음·전사문은 이 프로젝트 근거에 포함되지 않았다.

## 끝까지 다루지 않은 범위

노드 1의 FastText와 ELMo를 모두 깊게 학습한 것으로 처리하지 않는다. 사용자는 시간 관계상 Word2Vec 이후 노드 2로 이동했다. WPM의 likelihood 세부 계산도 사용자가 깊게 다루지 않고 넘어가기로 한 부분이다. 반복 시드 실험, 정규화만 통제한 인과 비교, 새 런타임 전체 재실행은 남아 있다.
